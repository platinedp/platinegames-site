# platinegames.com

Site de Platine Games : la page d'accueil de Brainrot TCG, aux couleurs du jeu.

Site statique (HTML et CSS, sans outil de construction), publié par GitHub Pages depuis la branche `main`.

- `index.html` : la page
- `style.css` : les styles (jetons de la charte de Brainrot TCG)
- `assets/` : vidéo, illustrations, cartes, rangs
- `fonts/` : Baveuse (titres) et Les Flos (texte)

Pour la voir en local : `python -m http.server 8810`, puis http://localhost:8810
